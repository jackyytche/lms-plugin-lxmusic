# lms-plugin-lxmusic

**洛雪音乐** — 为 Daphile（Lyrion Music Server 定制 HiFi 系统）打造的 lx-music 自定义音源插件。

在达菲上直接使用洛雪音乐（lx-music）的订阅源：导入订阅（在线/粘贴/文件）、聚合搜索、
分类浏览、多音质选择、跨源自动降级播放。单插件自包含，无需外部服务。

> 项目与文档见内部工作区；本仓库托管插件发布（repo.xml + zip）与 QuickJS 引擎构建流水线。
> 仅供个人学习研究使用。

## 安装

达菲网页 → 设置 → 插件 → 第三方插件源 → 添加：

```
https://github.com/jackyytche/lms-plugin-lxmusic/releases/latest/download/repo.xml
```
